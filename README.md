# mcl_interchrom

This folder contains the scripts used for the downstream analysis and visualisation of the data from the *Schwager 2025* article (PMID: ). \
\
The raw sequencing data was generated in the CNRS UMR9018 and deposited to [GEO](https://www.ncbi.nlm.nih.gov/geo/) (GSE291373, GSE291374, GSE291376, GSE291377) or downloaded from [EGA](https://ega-archive.org/) (EGAD00001001502, EGAD00001001519, EGAD00001002397, EGAD00001002902, EGAD00001002918, EGAD00001002336, EGAD00001002315). 
\
The description of the scripts and data can be found in the sub-folders corresponding to each analysis.
