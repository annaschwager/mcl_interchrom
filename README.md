# mcl_interchrom

This folder contains the scripts used for the downstream analysis and visualisation of the data from the *Schwager 2025* article (PMID: ). \
The raw sequencing data was generated in the CNRS UMR9018 and deposited to [GEO](https://www.ncbi.nlm.nih.gov/geo/) (GSE291373, GSE291374, GSE291376, GSE291377) or downloaded from [EGA](https://ega-archive.org/) (add accession numbers).
